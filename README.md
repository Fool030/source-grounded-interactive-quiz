# Source-Grounded Interactive Quiz

강의 슬라이드와 녹취, PDF, DOCX, 노트를 바탕으로 **대화 안에서 풀고 제출하는 인터랙티브 퀴즈**를 만드는 ChatGPT 스킬입니다. 제출된 답안은 원본 자료를 기준으로 AI가 채점하며, 문항별 해설과 취약 개념에 대한 복습 방향을 제공합니다.

## 주요 기능

- **자료 기반 출제**: 제공된 자료를 최우선 근거로 삼고, 강의 내용과 AI의 보충 설명·응용 예시를 구분합니다.
- **범위 조절**: 슬라이드와 녹취의 대응 범위를 확인하여 이전 강의 복습이나 다음 강의 예고 등을 제외할 수 있습니다.
- **네 가지 문제 유형**: O/X, 4지선다 객관식, 단답형, 서술형을 함께 구성합니다.
- **개념부터 적용까지**: 정의, 비교, 계산, 설명 문제를 자료의 범위와 강조점에 맞춰 배분합니다.
- **영역별 풀이**: 현재 선택한 영역의 문제만 표시하고, 영역을 이동해도 입력한 답안을 유지합니다.
- **답안 보존**: 지원되는 환경에서 자동 저장·복원을 제공하며, 답안 복사·백업·재가져오기 경로를 마련합니다.
- **AI 채점**: 단답형의 동의어·동치 표현을 인정하고, 서술형에는 요구 요소별 부분점수를 부여합니다.

## 빠른 시작

1. 스킬을 사용할 수 있는 ChatGPT 환경에서 강의 자료를 첨부합니다.
2. `source-grounded-interactive-quiz` 스킬을 선택하거나 요청에 이름을 명시합니다.
3. 출제 범위와 원하는 문제 수·난이도 등을 적습니다.
4. 생성된 퀴즈를 영역별로 풉니다.
5. **제출 및 AI 채점** 버튼을 눌러 답안을 대화에 전송합니다.
6. 채점 결과와 해설을 확인하고, 필요하면 취약 개념 중심의 새 퀴즈를 요청합니다.

기본 언어는 한국어입니다. 다른 언어를 요청하면 문제, UI, 피드백에 일관되게 적용합니다.

### 기본 요청 예시

```text
@source-grounded-interactive-quiz
첨부한 슬라이드와 강의 스크립트를 바탕으로 인터랙티브 퀴즈를 만들어줘.
O/X, 객관식, 단답형, 서술형을 모두 포함하고,
강의 내용을 충분히 점검할 수 있는 수로 구성해줘.
정답은 제출하기 전까지 보여주지 마.
```

### 범위를 지정하는 요청 예시

```text
@source-grounded-interactive-quiz
Lecture8.pdf의 4–23쪽에 해당하는 내용만 출제해줘.
첨부한 녹취 중 해당 슬라이드를 설명하는 부분만 참고하고,
이전 강의 복습, 다음 강의 예고, 시험 공지는 제외해줘.
44문항, 100점으로 구성하고 개념·비교·계산 문제를 고르게 포함해줘.
```

### 맞춤 구성 예시

```text
@source-grounded-interactive-quiz
첨부 자료로 영어 퀴즈를 만들어줘.
총 20문항으로 구성하고, 계산과 개념 적용 문제의 비중을 높여줘.
서술형은 각 문제에서 요구하는 요소가 명확하도록 작성해줘.
```

## 입력 자료와 출제 원칙

슬라이드, PDF, DOCX, 강의 녹취, 텍스트 노트를 사용할 수 있습니다. 실제로 읽을 수 있는 자료가 필요하며, 파일에 접근할 수 없다면 재업로드가 필요합니다.

슬라이드와 녹취를 함께 제공하면 두 자료의 범위를 대조합니다. 녹취에 다른 강의가 포함되어 있더라도 지정된 범위에 해당하는 내용을 중심으로 출제합니다. 자료에 없는 내용은 임의로 강의 내용으로 취급하지 않으며, 추가 응용 문제는 별도로 표시합니다.

사용자가 지정한 문제 수, 범위, 유형 비율, 난이도, 만점, 채점 방식이 기본 설정보다 우선합니다.

## 문제 구성

문제 수는 자료의 학습 범위에 비례해 정합니다. 넓은 강의 전체를 다룰 때는 대체로 30–50문항을 시작점으로 삼으며, 다음 프리셋을 사용할 수 있습니다. **44문항은 고정 규칙이 아닙니다.**

| 유형 | 문항 수 | 문항당 배점 | 합계 |
| --- | ---: | ---: | ---: |
| O/X | 12 | 1점 | 12점 |
| 객관식 | 15 | 2점 | 30점 |
| 단답형 | 10 | 3점 | 30점 |
| 서술형 | 7 | 4점 | 28점 |
| **전체** | **44** | — | **100점** |

객관식은 단일 정답을 갖는 4지선다로 구성합니다. 단답형은 필요한 용어·공식·단위·결과를 명확히 지정하고, 서술형은 일반적으로 2–4개의 평가 요소를 제시합니다. 제출 전에는 정답이나 채점 키를 입력 화면에 노출하지 않습니다.

## 풀이, 저장, 제출

퀴즈는 영역별로 표시되며 진행률과 입력 상태가 연동됩니다. 모든 문항이 미응답이면 제출할 수 없고, 일부만 풀었다면 미응답이 0점 처리된다는 안내와 함께 제출할 수 있습니다.

자동 저장과 재진입 복원은 실행 환경의 저장 기능에 따라 지원 여부가 달라집니다. 저장할 수 없는 경우에는 풀이 전에 한계를 알리고 수동 백업을 제공합니다. **자동 저장이 모든 환경에서 보장되는 것은 아닙니다.**

답안 백업에는 기준 자료, 문제 원문, 객관식 선택지 전체, 현재 답안, 배점 및 채점 지침이 포함됩니다. 클립보드 접근이 막혀도 텍스트를 직접 선택해 복사할 수 있어야 하며, 백업을 가져와 답안을 복원하는 경로를 제공합니다.

제출 버튼은 답안과 채점 요청을 새 사용자 메시지로 전송합니다. 전송 API 호출의 성공과 실제 메시지 도착·채점 완료는 구분합니다.

## 채점과 피드백

| 항목 | 처리 원칙 |
| --- | --- |
| O/X·객관식 | 정답 여부에 따라 판정 |
| 단답형 | 동의어와 동치 표기 인정 |
| 서술형 | 답안 길이보다 요구 요소의 정확성으로 평가, 부분점수 인정 |
| 미응답 | 0점 처리 |
| 내용상 답이 아닌 입력 | `?`, `모르겠음` 등은 실질 응답으로 집계하지 않음 |
| 모호하거나 잘못 출제된 문항 | 문제의 불명확성을 밝히고 공정하게 처리 |
| 자료와 일반 지식의 차이 | 강의 설명과 보충·정정을 분리 |

채점 결과에는 다음이 포함됩니다.

1. 총점과 유형별·영역별 점수
2. 모든 문항의 정오 및 획득 점수
3. 오답과 부분점수 문항에 대한 해설
4. 핵심 취약 영역과 권장 복습 순서

필요하면 전체 만점 대비 점수와 실질적으로 응답한 문항만의 점수를 구분합니다. 문항별 점수, 유형별·영역별 소계, 총점의 합계도 검산합니다.

원본 자료에 계속 접근할 수 있는 **같은 대화에서 채점**하는 것이 기본입니다. 새 대화로 답안을 옮겼는데 원본 자료를 읽을 수 없다면, 그 제한을 밝히고 자료를 다시 제공받아야 합니다.

## 문제 발생 시

| 상황 | 대응 |
| --- | --- |
| 제출 실패 | 현재 답안을 먼저 복사·백업하고, 오류 정보를 확인한 뒤 재시도합니다. 백업 텍스트를 대화에 직접 붙여넣어 채점을 요청할 수도 있습니다. |
| 클립보드 복사 실패 | 백업 텍스트를 직접 선택해 복사합니다. |
| 퀴즈가 보이지 않음 | 같은 인라인 UI 방식에서 렌더링 오류를 점검·수정합니다. |
| 저장 기능 사용 불가 | 수동 백업을 사용하며, 새로고침이나 앱 종료 전에 답안을 보존합니다. |
| 기존 답안이 사라짐 | 실제 저장본이나 백업의 존재를 확인합니다. 저장본이 없다면 복구를 보장할 수 없습니다. |

장애 대응 순서는 **기존 답안 보존 → 오류 확인 → 수정 → 재검증**입니다. 백업 전에 새로고침이나 앱 종료를 먼저 시도하지 않는 것이 원칙입니다.

## 실행 환경과 한계

이 스킬은 독립 실행형 웹앱이 아니라, ChatGPT가 자료를 읽고 퀴즈를 생성·채점하도록 안내하는 지침 묶음입니다.

- 대화 내 퀴즈에는 호스트의 인라인 UI 기능이 필요합니다.
- 버튼 제출에는 문서화된 대화 전송 API가 필요합니다.
- 저장·복원과 클립보드 기능은 환경별 지원 여부를 확인해야 합니다.
- 인라인 UI가 지원되지 않으면 한계를 설명하고 대안을 선택받습니다. 외부 사이트나 HTML 파일로 임의 대체하지 않습니다.
- 문법 검사나 모의 테스트만으로 실제 화면·대화 전송까지 검증했다고 주장하지 않습니다.
- AI 채점은 원본 자료를 기준으로 수행하지만 오류 가능성이 있으므로, 이견이 있으면 해당 문항과 근거를 지정해 재검토를 요청할 수 있습니다.

## 스킬 구성 파일

아래는 스킬 패키지의 구성입니다. 이 README 파일 자체에 아래 파일들이 포함되는 것은 아닙니다.

| 파일 | 역할 |
| --- | --- |
| `SKILL.md` | 적용 조건과 전체 출제·풀이·채점 워크플로 |
| `references/inline-ui.md` | 대화 내 UI 구조와 제출 구현 패턴 |
| `references/reliability.md` | 답안 저장·복원·백업·오류 처리와 검증 기준 |
| `references/grading.md` | 출제 근거, 공정성, 부분점수, 성적표 작성 규칙 |
| `scripts/validate_bank.py` | JSON 문제 은행의 형식과 배점 합계를 검증하는 선택적 스크립트 |

UI를 구현할 때는 인라인 UI와 신뢰성 참고 문서를 먼저 읽고, 제출된 답안을 채점할 때는 채점 규정을 적용합니다. DIL 문법과 `GenUI.issueNewTurn(prompt)`는 해당 기능이 실제로 지원되는 환경에서만 사용합니다.

## 품질 확인 기준

- 기준 자료와 출제 범위를 실제로 확인했는가?
- 문항 수와 유형별·영역별 배점이 총점과 일치하는가?
- 요청한 유형과 핵심 개념이 충분히 포함되었는가?
- 영역을 이동하거나 전송을 재시도해도 답안이 유지되는가?
- 저장 상태와 수동 백업 경로가 명확한가?
- 제출 메시지에 미응답을 포함한 전 문항과 선택지가 들어가는가?
- 제출 전 정답을 노출하지 않았는가?
- 실제 검증한 기능과 확인하지 못한 기능을 구분했는가?
- 채점 결과의 소계와 총점이 일치하는가?
